# AI Review Service

Сервис формирует предварительную научную рецензию и рекомендацию к публикации.
Доступ к API имеют пользователи с ролью `editor` или `admin`.

## API

- `POST /api/ai-reviews` — создать запрос (ответ `202`, обработка продолжается в фоне).
- `POST /api/ai-reviews/stream` — сформировать рецензию потоково (`application/x-ndjson`).
- `GET /api/ai-reviews/{id}` — получить статус и результат.
- `GET /api/ai-reviews` — история запросов пользователя; администратор видит все.

Можно передать `article_id`, собственный текст рукописи или оба источника. Если указан
только `article_id`, сервис получает заголовок и аннотацию из Article Service, поэтому
помечает вывод как предварительный. Рекомендуется передавать `manuscript_text` для полной
рецензии.

Пример:

```json
{
  "article_id": 42,
  "manuscript_text": "Полный текст статьи...",
  "language": "ru",
  "additional_instructions": "Особое внимание уделить методологии"
}
```

Поле `recommendation` принимает одно из значений: `accept`, `minor_revision`,
`major_revision`, `reject`. Решение ИИ носит рекомендательный характер и не заменяет
редактора или независимое рецензирование.
